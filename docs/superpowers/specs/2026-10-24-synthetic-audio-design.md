# Synthetic ElevenLabs audio extension

> Superseded historical ElevenLabs record. The current implementation follows the [OpenAI audio design](./2026-10-25-openai-audio-design.md). Historical checks below describe the earlier provider and do not establish live OpenAI generation or listening results.

User authorization: implement the already deferred voice generation stretch with ElevenLabs. Transcripts remain template driven and unchanged. Main, backend, dashboard, and voice agent remain untouched. No commits or pushes.

## Behavior and shared contracts
- Separate opt-in audio CLI; existing offline transcript CLI stays offline. Node 24 builtins, no ffmpeg dependency.
- ElevenLabs POST /v1/text-to-speech/{voice_id}?output_format=pcm_16000, xi-api-key header, model eleven_multilingual_v2, seeded best-effort generation. Raw signed 16-bit little-endian mono PCM, 16000 Hz. Two configured voices; list preset voices via GET /v2/voices. No voice cloning.
- Read only canonical calls, synthetic timing, and manifest. Verify against regenerated deterministic bundleFiles from manifest raw configuration before any paid request; never read ground-truth files or send labels/IDs/timing to provider. Source files must be regular nonsymlink files under a nonsymlink directory.
- Split source text at planted word boundaries using UTF-16 source offsets. Each chunk is spoken separately; insert exactly durationMs*16 zero samples after that chunk. Between turns insert 250ms zeros. Do not impose original word times on speech. Provider speech can itself contain natural silence; recorded inserted spans are not total acoustic pauses. Chunking may affect prosody.
- Output explicitly SIMULATED WAVs (RIFF INFO comment too), audio timing JSON, manifest and README. Full conversation plus caller-only WAV on same timeline (agent speech muted); caller-only is for acoustic isolation, not a full speaker transcript. Audio utterance times derive from sample counts, no invented word times. Keep planned source timing separately referenced.
- Deterministic offline plan and assembly for identical PCM. Fresh provider synthesis is not guaranteed bit identical. Cache PCM by complete request hash, verify its digest, and reuse after partial failures. No automatic paid POST retries. Never overwrite output; a failed new output can remain incomplete. Cache may be reused in a fresh destination.
- API credentials only from process environment; document Node --env-file. Never print credentials/provider response bodies. No live request in tests. No database import or live detector call.
- CLI default dry-run; live requires --generate, explicit caller and agent voice env values, and API key. --list-voices reads available preset voices. Optional --limit selects earliest N calls (1..all); default all. --max-characters default100000 caps submitted text on whole selected plan before generating. --cache explicit existing/new directory required live; --output fresh directory required live. Dry run requires --input only.

### Module interfaces
1. src/audio-plan.mjs exports planAudioCall(call,timing,{seed,callerVoiceId,agentVoiceId,modelId='eleven_multilingual_v2'}). Returns {callId,elderId,startedAt,isSimulated:true,sampleRate:16000,turnGapMs:250,utterances:[{speaker,text}],segments:[{index,turnIndex,speaker,text,sourceStart,sourceEnd,afterPause:null|{afterWordIndex,durationMs},request:{voiceId,text,modelId,seed,previousText,nextText}}]}. Source offsets reference original turn text. previousText/nextText are adjacent context from the SAME turn, max1000 chars. No other fields in request. Validate malformed pauses, source/simulation/IDs/uint32. Does not need exactly8 pauses for unit fixtures; runner validates real source.
2. src/audio-pcm.mjs exports assembleAudioCall(plan,pcmBuffers) returning {conversationWav:Buffer,callerWav:Buffer,timing:Object}. Timing has callId,isSimulated:true,timingSource:'synthetic_audio_samples',sampleRate:16000,totalSamples,durationMs,utterances:[{speaker,text,startMs,endMs}],segments:[{index,turnIndex,sourceStart,sourceEnd,startSample,endSample}],insertedSilences:[{kind:'planted'|'turn_gap',turnIndex,startSample,endSample,durationMs,afterWordIndex?}], notice. Validate PCM nonempty even length, correct count, bounded sizes. WAV PCM mono16bit with simulation INFO comment. Bound total output to <=30min per call. No leakage of source word times. Export pcmToWav(pcm) for header tests.
3. src/audio-provider.mjs exports requestKey(request) SHA256 canonical allowlist; createElevenLabsProvider({apiKey,fetchImpl=globalThis.fetch}) -> {synthesize(request):Promise<Buffer>,listVoices():Promise<Array<{voiceId,name,labels}>>}; exports cachedSynthesize(request,{cacheDir,provider}):Promise<{pcm:Buffer,cacheHit:boolean,key:string}>. API uses fixed origin and safe voice ID; finite timeout/body size; redirect:error; safe stable errors only. Validate request inputs. Cache uses an exclusive single JSON envelope {schemaVersion:1,isSimulated:true,requestKey,sha256,pcmBase64} per hash so partial entries detected, no key stored. Existing corruption fails closed (no unexpected rebilling). Reject symlink cache directory/ancestors/files. Single-process sequential CLI, concurrent writers may fail safely without overwriting. listVoices pagination and only default preset voices.
4. src/audio-run.mjs exports loadAudioSource(inputDir) -> {manifest,calls,timings} verifying source as above, and runAudio({inputDir,outputDir,cacheDir,generate=false,limit,maxCharacters=100000,callerVoiceId,agentVoiceId,apiKey,provider?}) -> summary {isSimulated:true,dryRun,callCount,segmentCount,characterCount,...}. Dry-run placeholder voice IDs allowed if unset. Live validates full plan/budget/options and reserves fresh destination BEFORE provider calls. Writes synthetic filenames and manifest last, sha256 hashes. File output paths from validated stable callIds; no overwrites/symlink destinations. provider injection for tests only. CLI parses strict documented options, --help, --list-voices standalone, safe errors. No credentials/content printed. CLI summary can show paths/counts. Audio manifest records source manifest hash, config, voice/model IDs, request keys, file hashes and cache hits; no secret/no truth.

## Acceptance
Tests first: exact real zero samples; caller track preserves timeline; source text spans, pause indices, no label/request leakage; provider boundary/auth/errors/no retries/cache integrity; safe source/output paths; dry run no network; live mocked end-to-end WAV with correct digest and timing; cap and malformed source fail before calls; same cached bytes identical output payloads (manifest cache-hit counts may differ; record counts in run summary rather than deterministic manifest). Re-run complete synthetic and detector suites plus syntax checks. Separate software success from live synthesis/subjective voice quality. No claim of accuracy or medical inference.
