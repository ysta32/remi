# Exact detector shared contract
Scope: detector/ and its accompanying design/integration documentation. No dependencies. Node24 native ES modules, node:test. Relative imports include .mjs. Tests exercise production functions with injected HTTP boundary fetchImpl only (not injected extract/compare functions).

Error: `class DetectorError extends Error { constructor(code, message); code }`; messages fixed safe text, never interpolate values from user/provider/key. Validation errors code INVALID_INPUT or INVALID_HISTORY, provider codes CONFIGURATION_ERROR, PROVIDER_ERROR, PROVIDER_TIMEOUT, INVALID_RESPONSE, EXTRACTION_REFUSED, EXTRACTION_INCOMPLETE, INCOMPATIBLE_EMBEDDINGS, CONSENT_REQUIRED. No raw cause/body in exported errors.

`parseCall(value)` returns NEW object {elderId,callId,startedAt,isSimulated,utterances}. IDs nonempty <=200 chars; startedAt valid ISO datetime WITH timezone canonicalized to UTC; isSimulated boolean default false; utterances array <=1000, total chars <=120000; each {speaker:'caller'|'agent',text,startMs?,endMs?}; text string <=20000; blank text allowed (empty call legitimate); if one offset supplied both required nonnegative finite integer end>=start. Does not truncate or mutate. Unknown properties dropped. Empty utterances valid.

ExtractedItem shape: {id,elderId,callId,startedAt,isSimulated,kind:'story'|'question',summary,quote,sourceTurnIndex,elicitation:'unprompted'|'prompted'|'uncertain',promptTurnIndex:number|null}. summary nonempty <=280, quote nonempty <=1200. quote must be literal substring of call.utterances[sourceTurnIndex].text where speaker caller. For prompted, promptTurnIndex must reference preceding agent turn; for unprompted/uncertain null. Stable id via `makeItemId({elderId,callId,kind,sourceTurnIndex,quote})`: SHA256 structured JSON prefixed `item_`, no display text. Exact repeat of same extraction item is rejected, not double-counted. Extraction prompt asks one item per distinct incident/question in a call, merging mentions of same incident; algorithm cannot guarantee semantic dedup until evaluated.

EmbeddedItem = ExtractedItem plus {embedding:number[],embeddingModel:string,embeddingDimensions:positive integer}. SavedItem = ExtractedItem plus optional embedding (null or omitted) and optional embeddingModel/embeddingDimensions (null/omitted allowed only when no vector), extractionModel?:string,promptVersion?:string. Vector present => model and dimensions required, finite nonzero vector with matching dimension. `parseHistory(value)` accepts SavedItem[], max 100000; new validated objects, duplicates by id rejected. Cannot quote-check against absent previous transcripts; shape only. Future/foreign history validated structurally then filtered by pipeline before provider use.

Options shared: {apiKey,extractionModel,embeddingModel='text-embedding-3-small',embeddingDimensions=1536,fetchImpl=globalThis.fetch,timeoutMs=30000,maxRetries=1}. No arbitrary base URL. apiKey nonempty without logging. extractionModel required only for extraction (no default). Timeout clamp/validation 1..120000; maxRetries 0..1. `postOpenAI(path,body,options)` accepts only '/responses' or '/embeddings', POST fixed https://api.openai.com/v1; Authorization Bearer apiKey; Content-Type JSON; redirects error; retry network errors,429,5xx once; abort timeout bounded; sanitize provider errors and body parse errors; never log. Return parsed JSON. Set Responses store:false in extraction body. Test real HTTP shape with injected fetchImpl producing Response objects. Bound retry delay <=250ms; timeout must end even when response body stalls.

`extractItems(call,options)` takes parsed Call; validates as needed. Returns {items:ExtractedItem[],extractionModel,promptVersion:'remi-items-v1'}. Empty/all-whitespace caller text => items[] no HTTP. Responses request strict text.format json_schema for {items:[{kind,summary,quote,sourceTurnIndex,elicitation,promptTurnIndex}]}, additionalProperties:false recursively. instructions separate trusted system/developer text from JSON serialized transcript user input; full transcript only in user input. No output history to extraction. Parse completed response.output message content output_text; reject refusal, incomplete/noncompleted, absent/duplicate or invalid text, malformed schema, fabricated quote, wrong caller attribution/metadata. Add IDs and call metadata locally, not from model. Fail on invalid output, do not silently omit items. Maximum 500 extracted items; beyond fails. Do not perform second semantic verify.

`embedItems(items,options)` returns new EmbeddedItem[] using summary only as embedding input; new items IDs unique; no-op [] with zero calls. Sends model, dimensions, encoding_format:'float', input string[]. Batch max100. response.model must equal requested; validate exactly one indexed vector per input; reorder by index. For cache `prepareHistory(history,options)`: compatible existing vectors reused; missing vectors generated; incompatible existing model or dimensions => INCOMPATIBLE_EMBEDDINGS rather than silently mixing. Keep history provenance fields. No embedding requests for already cached compatible items. Never overwrite older extractionModel/promptVersion.

`cosineSimilarity(a,b)` validates equal nonzero dimension, finite nonzero vectors; scale-stable algorithm prevents overflow/underflow; result finite clamp[-1,1]. `findCandidates(current:EmbeddedItem[],history:EmbeddedItem[])` => Candidate[] where {item:EmbeddedItem,bestMatch:EmbeddedItem|null,similarity:number|null,eligibleCount:number}. One per unique current id (duplicates invalid). Eligible = same elderId, different callId, history.startedAt < item.startedAt, same kind, any age. Eligible incompatible model/dimension => INCOMPATIBLE_EMBEDDINGS. Missing eligible vector => invalid/unavailable not ignored. Tie: higher similarity, then more recent startedAt, then lexical id ascending. No threshold in this function. Do not compare current items with each other.

`classifyCandidates(candidates,{threshold=0.85}={})`: threshold finite [0,1]. Match shape {itemId,kind,elicitation,isRepeat,similarity,matchedItemId,matchedCallId,candidateItemId,candidateCallId,eligibleCount}. candidate IDs retain best even below threshold; matched IDs only set when repeat else null. bestMatch=null => similarity=null and no repeat even threshold0. isRepeat similarity>=threshold. counts shape {total,unprompted,prompted,uncertain,stories,questions}, all integers, only repeats counted. Invalid/duplicate candidate ids, invalid score/label/kind, malformed best/score association rejected. Return {matches,counts,threshold}.

`analyzeCall(input,options={})`: input {call,history:SavedItem[],processingAllowed:boolean}; require true before any provider call. parseCall and parseHistory, strictly filter history same elder different older call and kinds extracted before prepareHistory. options includes threshold default0.85 and above OpenAI options. Return success {status:'ok',persistenceKey:'call_'+SHA256(JSON.stringify([elderId,callId])),elderId,callId,items:EmbeddedItem[] with extractionModel/promptVersion,historyUpdates:EmbeddedItem[] only newly embedded prior eligible items, matches,counts,provenance:{detectorVersion:'1.0.0',extractionModel,promptVersion:'remi-items-v1',embeddingModel,embeddingDimensions,threshold,isSimulated}}. No raw transcript in result. Errors return {status:'unavailable',elderId:string|null,callId:string|null,items:[],historyUpdates:[],matches:[],counts:null,error:{code,message}}. Do not leak invalid identifiers into error message; unavailable identifiers only validated safe values or null. Do not convert errors to success. No usable caller text=>success empty without network/model key requirement; provenance extractionModel may null when not invoked. Empty extraction=>skip embedding/history. Pipeline does no caching/storage itself; stable id/upsert docs handles reprocessing without duplicate rows. Successful retries may yield different extraction; caller REPLACES per-call rows transactionally, never appends. Caller must prevent stale jobs restoring deleted data/consent.

CLI input JSON matches analyzeCall input, no apiKey. Reads key OPENAI_API_KEY and extraction model OPENAI_EXTRACTION_MODEL, optional EMBEDDING_MODEL/EMBEDDING_DIMENSIONS/REPEAT_THRESHOLD from process.env. API key never accepted via CLI args. CLI writes explicitly requested JSON result file mode0600, exclusive create (refuse overwrite), no text or key printed. stderr safe status/error code only, nonzero unavailable/invalid args. `--help` no credentials required. Use --env-file-if-exists=.env.local manually if needed; never read other projects' secrets. Example fictional fixture labeled call.isSimulated:true. Live command requires user-provided key; deterministic tests never touch real service.
